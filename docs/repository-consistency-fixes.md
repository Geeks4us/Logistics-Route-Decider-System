# Repository consistency fixes

## Issues resolved

1. Hidden-character duplicates were creating confusing duplicate entries in the repository tree.
2. Wildcard placeholder filenames were treated as literal file names instead of real documentation artifacts.
3. Empty evidence content made the review artifact appear incomplete.

## Canonical naming used now

- `docs/use-cases/UC-01.md`
- `models/domain-model.md`
- `evidence/lab-05-review.md`

These names align with the rest of the repository and support consistent documentation navigation.
