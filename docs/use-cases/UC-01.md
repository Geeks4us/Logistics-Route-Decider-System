# Use Case UC-01: Create and Evaluate a Delivery Batch

## Summary
The dispatcher creates a delivery batch, validates the available vehicle capacity, and evaluates a candidate route before approval.

## Primary actor
- Dispatcher

## Preconditions
- A vehicle is available for the route window.
- At least one delivery order exists with destination, time window, and priority.

## Main flow
1. The dispatcher creates a batch of delivery orders.
2. The system validates each order's destination, time window, and priority.
3. The system checks the selected vehicle's weight and volume limits.
4. The system retrieves a distance matrix from the external mapping service.
5. The system generates an optimized route.
6. The dispatcher reviews the route proposal.
7. The dispatcher approves or rejects the route before assignment.
8. If approved, the route moves to the assigned state.

## Alternate flows
- If a vehicle exceeds capacity, the system rejects the assignment.
- If the mapping service is unavailable, the route generation fails with a clear error to the dispatcher.
- If a route is rejected, the system returns to draft state and allows editing.
