# Logistics Route Decider System

This repository contains the planning, requirements, modeling, and review artifacts for the Logistics Route Decider System.

## Contents

- `docs/requirements.md` — functional and non-functional requirements
- `docs/consistency-matrix.md` — traceability between requirements and design decisions
- `docs/use-cases/UC-01.md` — canonical use case definition for route planning
- `models/domain-model.md` — core domain entities and relationships
- `evidence/lab-05-review.md` — review notes for the consistency pass

## Consistency cleanup

The repository had several naming and placeholder inconsistencies (including hidden-character duplicates and wildcard-style placeholder filenames). These have been normalized to concrete, readable filenames so the project documentation is easier to navigate and review.
